**LexiForge** is a premium, 100% offline flashcard and vocabulary app for Android. Unlike simple flashcard apps, LexiForge uses the **SM-2 Spaced Repetition Algorithm** (the same logic used by Anki) to calculate the exact optimal time to show a card again based on memory retention. 

No accounts. No cloud. Just pure, scientifically proven memory training.

---

## ✨ Features

*   🧠 **SM-2 Algorithm:** Scientifically proven spaced repetition scheduling.
*   🗣️ **Text-to-Speech (TTS):** Pronounce words in multiple languages (Hindi, Japanese, Spanish, etc.).
*   📊 **Daily Goal Ring:** Track your daily progress with a beautiful circular progress bar.
*   🔥 **Streaks & XP:** Gamified learning to keep you motivated.
*   🗂️ **CSV Import/Export:** Backup your decks and cards easily.
*   🎨 **Premium UI/UX:** "Midnight Scholar" theme with Glassmorphism effects, 3D card flips, and haptic feedback.
*   🔒 **100% Offline & Private:** All data is saved locally using Room DB.
*   💰 **Ad-Aware:** A single, non-intrusive AdMob banner that never interrupts studying.

---

## 🛠️ Tech Stack

*   **Language:** Kotlin
*   **UI:** Jetpack Compose (Material 3)
*   **Local Database:** Room DB (with KSP)
*   **Architecture:** MVVM + Clean Architecture
*   **Asynchronous:** Coroutines + Flow
*   **Monetization:** Google AdMob & UMP Consent
